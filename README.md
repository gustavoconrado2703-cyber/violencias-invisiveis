# Violências Invisíveis — versão 2.0
Projeto juvenil ligado ao Se Liga Moçada.
A experiência inclui abertura, quiz, cartões interativos, reflexão sobre masculinidades, pesquisa demonstrativa, compromisso Não Normalize e equipe.
A pesquisa desta versão armazena respostas apenas na sessão do navegador. Para coleta real, conecte Google Forms, Microsoft Forms, Supabase, Firebase ou outro backend.
Publique no GitHub Pages com `index.html` na raiz do repositório.
