# Violências Invisíveis — site do projeto

## Conceito
Site educativo e interativo com foco em reconhecer violências que podem ser normalizadas por não deixarem marcas físicas.

## Estrutura
- Abertura / conceito
- Quiz "Você reconheceria?"
- Tipos de violência
- Frases do cotidiano
- Pesquisa de percepção
- Orientação geral sobre busca de ajuda

## Como usar
Abra `index.html` em um navegador. O site funciona localmente sem servidor.

## Para transformar em projeto acadêmico
1. Substitua os textos demonstrativos pelos dados e referências definidos pelo grupo.
2. Faça uma pesquisa real com formulário externo (Google Forms, Microsoft Forms etc.) e substitua os resultados demonstrativos.
3. Inclua referências bibliográficas e fontes oficiais na versão final.
4. Adapte o conteúdo ao recorte definido pelo professor.
