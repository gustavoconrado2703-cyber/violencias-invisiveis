# Violências Invisíveis — versão 2.0

Projeto de conscientização e protagonismo juvenil ligado ao Se Liga Moçada.

## Autoria
Gustavo Conrado · Ray Wemeson · Railson · David

## O que esta versão possui
- Abertura narrativa
- Quiz interativo com 6 situações
- Mapa de formas de violência
- Reflexão sobre masculinidades
- Frases interativas
- Pesquisa de percepção com resultados da sessão
- Chamada para ação
- Layout responsivo para celular

## Publicação
Substitua os arquivos da versão anterior no GitHub Pages pelos arquivos desta pasta.

## Observação sobre pesquisa
A pesquisa embutida é demonstrativa e mantém contagens apenas durante a sessão do navegador. Para coleta acadêmica real, conecte as perguntas a Google Forms, Microsoft Forms ou backend/banco de dados e informe os critérios de anonimato e consentimento definidos pelo projeto.

## Fontes
Antes da entrega final, acrescente uma seção de referências com as fontes oficiais e bibliográficas adotadas pelo grupo, especialmente para definições legais e orientações de apoio.
